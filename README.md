# Noor Fatima | Quantum Computing / QML

An independently deployable static research portfolio focused on hybrid quantum-classical methods, variational circuits, QAOA, and quantum simulation.

## Run
`npm run build` creates `dist/`. Serve `dist/` with any static host.

## GitHub Pages
The included GitHub Actions workflow builds `dist/` and deploys it to `https://noor-fatima-afzal.github.io/P3/` on pushes to `main`.
